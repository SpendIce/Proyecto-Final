# Triage labels

| Rol canonico | Etiqueta del tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Requiere evaluacion del responsable |
| `needs-info` | `needs-info` | Espera informacion adicional |
| `ready-for-agent` | `ready-for-agent` | Esta especificado y listo para un agente |
| `ready-for-human` | `ready-for-human` | Requiere intervencion humana |
| `wontfix` | `wontfix` | No sera ejecutado |

Cuando una skill mencione un rol de triage, debe usar la etiqueta correspondiente de esta tabla.
