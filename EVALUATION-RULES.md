# Reglas de evaluacion del estudio

Estas reglas guian la generacion de ejercicios para preparar el parcial de gestion de proyectos.

## Principios

- Usar preguntas situacionales, no preguntas que se respondan por reconocimiento literal de una palabra clave.
- Incluir distractores plausibles cuando haya que elegir entre conceptos cercanos.
- Pedir justificacion breve, no solo nombre del concepto.
- Alternar preguntas de definicion, clasificacion, comparacion y aplicacion.
- Usar ejemplos vinculados a proyectos informaticos, gestion academica o Proyecto Final cuando ayuden a fijar el concepto.

## Evitar

- Enunciados que incluyan la respuesta, por ejemplo: "hay una EDT detallada, que metodo usas".
- Listas en el mismo orden que el apunte cuando el objetivo sea evaluar memoria.
- Casos con una sola pista obvia y ninguna ambiguedad real.

## Preferir

- Casos con informacion incompleta donde el alumno deba pedir o inferir datos razonables.
- Comparaciones entre dos alternativas correctas pero con distinta conveniencia.
- Preguntas que obliguen a distinguir concepto, herramienta y ejemplo concreto.

## Ejemplo de transformacion

Pregunta debil:
"Tenes una EDT detallada. Que metodo de estimacion usas?"

Pregunta mejor:
"El equipo ya descompuso el modulo en 18 paquetes, cada responsable conoce su parte, pero no hay datos historicos confiables. Que metodo usarias para estimar y que riesgo tendrias que cuidar?"
