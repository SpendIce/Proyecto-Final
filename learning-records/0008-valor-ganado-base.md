# Valor ganado base

El usuario calculo correctamente PV, AC, EV, CV, SV, CPI, SPI y EAC en un caso situacional, e interpreto que el proyecto esta atrasado y con mal desempenio de costo. Ajuste fino: cuando AC es menor que PV pero mayor que EV, no se gasto mas que lo planificado a la fecha en terminos absolutos, sino mas que el valor presupuestado del trabajo realmente producido.
